# Offers

Offers are cards that promote something: a special dinner, an experience, an upgrade, or a seasonal programme (for example Christmas week).

<figure><img src="assets/img/offer-edit.webp" alt="The fields of an offer"><figcaption>An offer being edited.</figcaption></figure>

| Field | What it does |
|---|---|
| **Offer Type** | Dining, Experience, Upgrade, Generic or Seasonal Update |
| **Card Title** / **Note** | The text on the card. If the title is empty, the item title is used |
| **Placement Screen** | Where it shows: Today, Dining or Experiences |
| **Active From / Active To** | The days the card is visible |
| **Linked Excursion / Linked Daily Content** | Optional. The ID of the experience or menu the card opens |
| **CTA Label / CTA Action** | The button text, and what it does: nothing (View Only), send a message to the desk, or open a link |
| **Seasonal Intro / Seasonal Programme** | For seasonal offers: a short intro, and one row per day. Put each time slot on its own line: `7:00pm - 8:00pm | Carols by the pool` |

?> **Where do I find an ID?** Open the experience or menu. The ID is the number after `post=` in the browser address, for example `post.php?post=409&action=edit`.
