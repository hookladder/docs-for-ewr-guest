# Glossary

| Term | Meaning |
|---|---|
| **wp-admin** | The WordPress administration area, where you work |
| **Guest app** | The website the guest uses on their phone. It can be installed on the home screen like an app |
| **Stay** | One guest's visit: name, room and dates |
| **Private link** | The personal address of a stay. Opening it signs the guest in |
| **Excursion / Experience** | Anything a guest can do or book, including spa treatments |
| **Booking** | A guest's request for an experience. Pending, confirmed or declined |
| **Daily Content** | The menu of one meal on one day |
| **Alert** | A short notice on the Today screen, for a limited time |
| **Offer** | A promotional card |
| **Featured image** | The main picture of an item |
| **ID** | The number WordPress gives each item. You see it in the address: `post=409` |
| **Publish / Update** | Save a new item / save changes. Nothing reaches the app without it |
| **Trash** | Where deleted items wait for 30 days before disappearing |
